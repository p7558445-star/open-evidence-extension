NCCN link redirect

Rewrite NCCN guideline PDF links on OpenEvidence — in a tab and in the side pane — to your own viewer. Redirected links always open in a new tab.

$cancer is the guideline slug (e.g. b-cell), $page the page number. Local file example: file:///Users/you/Downloads/NCCN/$cancer.pdf#page=$page — file:// targets need “Allow access to file URLs” enabled for this extension on chrome://extensions.

PICO rewrite
